# src/data/

Markdown では管理しない、サイト構造に近い固定データを置きます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `navigation.ts` | グローバルナビの表示名、ページタイトル、リンク先 |
| `othersSections.ts` | Others 配下のタブ定義とデフォルト遷移先 |

## 編集の目安

- ページやタブを増やす場合は、対応する `pages/` と一緒にここを更新する。
- `href` はサイト内の素のパスで定義し、表示時に `withBase()` を通す。
- ユーザー向けの長い文章や本文データは `src/content/`、画面ラベルは `src/msg/` を優先する。
