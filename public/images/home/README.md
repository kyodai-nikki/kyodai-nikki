# public/images/home/

Top page carousel images live here.

- Desktop images: place matching filenames under `pc/`, for example `pc/home.png`, `pc/1.png`, `pc/2.png`.
- Mobile images: place matching filenames under `mobile/`, for example `mobile/home.png`, `mobile/1.png`, `mobile/2.png`.
- If a mobile image is missing, the matching desktop image is used as the fallback.
